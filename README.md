# biopharma_portfolio_ops

An AtScale SML semantic model of the `BIOPHARMA_PORTFOLIO_OPS` schema in database `SUPPLY_CHAIN_OTD_DEMO`, through
the AtScale data connection `Snowflake Partner`.

- `catalog.yml` and `connections/` are the SML repository files.
- `context/` holds the inputs that the semantic model was built from;
  `context/manifest.yaml` says where they came from.
- `build.yaml` holds the settings for the build-model skill.

Publish through git and AtScale Design Center.
